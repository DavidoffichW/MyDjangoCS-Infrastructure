# Source and reference boundary

MyDjangoCS-Infrastructure is an independent implementation. No external
application source, private dataset, Git history, or embedded documentation is
required to build or run it.

The GPL-3.0 `django_htmx_dynamic_forms` tutorial was inspected at revision
`13f2bf04453d5230e42455f68213f2526ee1f6c9`. Its fragment-oriented ModelForm
interaction informed the research comparison, but no implementation or
template was copied.

HTMX 2.0.11 is vendored from its official project under the Zero-Clause BSD
license. Django and django-htmx are installed dependencies. The independently
authored application source is licensed under MIT. Those licenses do not grant
rights to unrelated external references, which remain outside this repository.
